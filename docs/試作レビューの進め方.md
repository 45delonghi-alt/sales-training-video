# 試作版（方式C）のレビューの進め方

目的：本制作（方式A/B）に進む前に、**「上長が“場面から入る1on1”をイメージできるか」**を確かめる。
見た目の完成度ではなく、**会話の中身と流れ**を評価してもらう。

## 実施概要

| 項目 | 内容 |
|---|---|
| 誰に | 営業部の上長 2〜3名（1on1の進め方を学んでいない人を1名以上）＋ 部下役の若手 2名 |
| 何を | `out/prototype_1080p.mp4`（素材なし版。人物はシルエット、音声なし・字幕のみ） |
| どう | 研修本番と同じく「上映 → 討議の問い」まで見てもらい、その場で下の質問に答えてもらう（15分） |
| 判断基準 | 下の「合格ライン」 |

## 質問（上長向け）

1. Before の1on1は、自分や周りの1on1に近いか？（近い／やや近い／遠い）→ 遠い場合、どこが違うか
2. After を見て、次の1on1で最初に何を聞くか言えるか？ → 実際に言ってもらう
3. 「点数より場面から入る」理由を、自分の言葉で一言で説明できるか？
4. 不自然な台詞・現場で言わない言い回しはあったか？（台詞ID で指摘）
5. 尺（約5分25秒）は、研修冒頭の上映として長い／ちょうどよい／短い？

## 質問（部下役の若手向け）

1. 「うちの職場っぽいか」（PART 3 の確認方法）
2. Before の佐藤さんの「心の声」に共感するか？
3. After の田中課長の聞き方をされたら、話しやすいか？

## 合格ライン（本制作に進む条件）

- 上長の過半数が、質問2で「最初の質問」を具体的に言える（例：「一番手応えがあった商談は？」）
- 上長の過半数が、質問3を自分の言葉で説明できる
- 「不自然な台詞」の指摘は、台本（`src/script.json`）を直して再出力してから本制作へ

満たさない場合は、映像ではなく**台本（会話の中身）**を見直す。

## レビュー後の流れ

1. 指摘を台詞ID ごとに整理し、`src/script.json` を修正
2. `npm run csv` で音声合成用の一覧を出し直し、音声を作成
3. 画像・音声を差し替えて `npm run durations` で尺を確認 → `npm run render`
