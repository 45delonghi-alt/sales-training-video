# 02　全60分の改訂ストーリー

導入資料（intro-slides.pptx・導入動画）で**理解したこと**を、WEB本編で**実践する**。本編では知識を再講義せず、「覚えていますか？」「今回はどれが適していますか？」「試すとどうなりますか？」の形で使わせる。

## タイムテーブル

| 時間 | フェーズ | 学生がすること | 主な場面 | 導入資料とのつながり |
|---|---|---|---|---|
| 0〜5分 | 導入 | 導入動画を見る（3か所で止まって考える） | 導入動画 → YOUR MISSION「ここからは、あなたが営業担当です。」 | P1〜24。P23「FIRST STEP：まずはお客様に現状を確認」で本編へ |
| 5〜15分 | PHASE 1 聞く | 何を確認するかを**選ぶ**（2問） | 佐藤さんの相談 → P1-Q1 → 現状データ → P1-Q2 → PHASE 1 CLEAR | P7〜9「何を確認する？」を、実際に聞いて確かめる |
| 15〜25分 | PHASE 2 考える | 調べる場所と確かめ方を**選ぶ**（2問） | 現場のセンサ → P2-Q1 → 仮想検証 → P2-Q2 → 原因の仮説 → CLEAR | P16「回帰反射型」を想起。正しい設置（片側・ボトル下部・反射板）を現場で確認 |
| 25〜35分 | PHASE 3 課題を見つける | お客様の**本当の課題**を見つける（2問） | 「何とか対応できています」→ P3-Q1 → P3-Q2 → お客様の本当の課題 → CLEAR | P10〜12「お客様が実現したいこと」を会話から引き出す（図は再掲しない） |
| 35〜50分 | PHASE 4 提案する | 方式を**判断**し、**30秒で提案**し、**実機で確かめる** | P4-Q1 → なぜ透明体専用か → KR-Qシリーズ → 30秒の提案 → 比較デモ3条件 → 結果 → P4-Q3 → CLEAR | P18「透明体専用」・P21「どれが最適か」・P22「透明。どの方式が合いそう？」の答え合わせ |
| 50〜60分 | 振り返り | 自分の言葉で書く・共有する | 振り返り4問 → 最後のメッセージ → エンディング | P1・P24「現場の課題を見つけ、解決策を提案する」に戻る |

## 一貫させた設定

| 項目 | 設定 |
|---|---|
| 既設設備 | 他社製の**一般的な回帰反射型**光電センサ（透明体専用ではない）。メーカー名は出さない（実在製品の性能不良を創作しない） |
| 設置 | コンベアの片側に投光・受光一体のセンサ、反対側に反射板。**ボトル下部を横から**。光はセンサ→ボトル下部→反射板→センサ |
| 課題 | 透明PETボトルの過剰カウント。通常＋0.5〜0.8%、多い週だけ最大＋3.0%（毎週ではない） |
| 数値の扱い | 導入P6「1,260本／1,262本」は**ある時点のカウント**。本編の週次記録（1万本あたり）とは別の集計。置き換えない |
| 原因 | センサ出力とPLCのカウントを切り分ける → ボトル下部の凹凸・揺れ・光量変化・光軸・感度。**仮説**として扱う |
| 本当の課題 | 正確な数量管理と、数え直し・ライン停止の削減（その先に安定した生産） |
| 提案 | OPTEX-FAの透明体専用の回帰反射型（候補：KR-Qシリーズ）。「必ず直る」とは言わない |
| ゴール | 既設と提案センサを同じ条件で比べ、お客様と一緒に確かめる。次は実際のラインで |
| 人物 | お客様：佐藤さん（女性・設備課）、高橋さん（女性・品質管理）。OPTEX-FA：森さん（女性・営業の先輩）、中田さん（男性・技術） |
