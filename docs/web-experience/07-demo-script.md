# 07　実機比較デモ台本

既設の**他社製・一般的な回帰反射型センサ**と、**OPTEX-FA 透明体専用の回帰反射型センサ（候補：KR-Qシリーズ）**を、同じ条件で比べる。目的は「どちらが高性能か」を決めることではなく、**今回のお客様のボトルと条件で、安定して数えられるか**をお客様と一緒に確かめること（導入P21）。

## 1. 準備（開始前に進行役・技術担当）

| 項目 | 内容 |
|---|---|
| ボトル | お客様と同じ透明PETボトル（中身入り）。本数を数えておく（例：200本） |
| 搬送速度 | 生産時と同じ速度（お客様は「速度は落とせない」と言っている） |
| 設置 | 2台のセンサを**同じ側**の**ボトル下部の同じ高さ**に、横向きで取り付ける。反射板はそれぞれの真向かい・同じ高さ |
| 反射板・設定 | それぞれのメーカーの使用条件に合ったもの（両製品の適正な使用条件を守る。片方だけ不利にしない） |
| 記録 | 通過本数（目視・別の計数器）／センサ出力の回数（表示灯・ロガー）／PLCのカウント値 |
| 画面 | 進行役画面の「実機デモの記録」に入力すると、学生全員の画面に「実測」として出る。入力しなければ「仮想データ（教育用）」と表示される |
| 製品情報 | KR-Qシリーズの仕様・数値は、**当日までに公式資料で確認**したものだけを話す（12-open-issues.md） |

## 2. 進行（約4分）

| 時間 | 画面（進行役が進める） | 話すこと | 学生の画面 |
|---|---|---|---|
| 0:00 | 比較デモの準備 | 「同じボトル、生産時と同じ速度、ボトル下部の同じ高さで比べます。測るのは、通過本数、センサの出力の回数、PLCのカウントです」 | 準備の映像 |
| 0:40 | 比較デモ1：通常搬送 | 「まず普段どおりに流します。1本につき、出力は1回でしょうか」→ 流して記録 | 映像＋記録の表 |
| 1:50 | 比較デモ2：悪条件（ボトルの揺れ） | 「佐藤さんの『流れが乱れるとき』を再現します」→ ガイドの当たりを変えて揺らす | 同上 |
| 3:00 | 比較デモ3：悪条件（間隔が詰まる） | 「間隔が詰まると、区切りが分かりにくくなります。多く数えないか、少なく数えないか、両方見ます」 | 同上 |
| 4:00 | 結果の比較 | 「記録した条件では、こうでした。まだ確かめていない条件もあります」 | 3条件の比較表 |

## 3. 判定の基準（試す前に決める）

| 基準 | 内容 |
|---|---|
| 1本につき出力1回 | 通過本数＝センサ出力の回数 |
| 本数が合う | 通過本数＝PLCのカウント値 |

両方を満たしたときだけ「基準を満たした」。満たさない・記録がない場合は、P4-Q3のあとに「基準に届かなかったとき」（設置の位置・角度／感度／PLC側の処理／別の方式）へ進む。

## 4. 言ってはいけないこと

- 「KR-Qなら必ず直ります」「他社製だから起きました」
- 公式資料で確認していない性能・数値
- 仮想データを実測のように話すこと（画面にも「仮想データ」と出る）

## 5. 最後の問い（P4-Q3）につなぐ

「実機で良い結果が出れば、すぐ採用を決めてもよいでしょうか？」→ 推奨はB「実際のラインでも確認する」。デモの条件と実際のラインの条件は同じではない。お客様の最後の言葉「ぜひ、実際のラインでも一緒に確認させてください」で、提案が**次の一歩**につながったことを示す。
