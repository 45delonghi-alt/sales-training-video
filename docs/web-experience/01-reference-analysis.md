### 4-2. 技術的な誤り（参考画像・導入動画）

正しい設置は「コンベアの片側に投光・受光一体のセンサ、反対側に反射板。ボトル下部を横から。光はセンサ→ボトル下部→反射板→センサ」。

| 資料 | 場所 | 誤り | 本編での扱い |
|---|---|---|---|
| 導入動画 | 0:30〜0:48（P6） | センサが**上から真下に**光を出し、反射板がない（透過・反射の区別がない概念図） | 導入動画のこの区間だけ、ソースの正しい設置図（横・低位置・反射板あり）に差し替えた版を作る。元の音声・字幕はそのまま |
| 参考画像 | 4・10コマ | 文が「透明体検出用の反射型光電センサを使用」となっている | 既設は**一般的な回帰反射型（透明体専用ではない）**に統一 |
| 参考画像 | 5コマ | 左右の機器がどちらもセンサに見え、反射板が分からない | 片側＝センサ、反対側＝反射板を描き分ける |
| 参考画像 | 6コマ | 「間隔が狭いと1本を複数回カウント」 | 間隔が詰まると区切りがなくなり**少なく数える**方向にも働く。「増えるかは要確認」として扱う |
| 参考画像 | 7コマ | 「天面・肩部からの反射光」「ラベルの有無」 | 検出位置はボトル**下部**。天面・肩・ラベルは検出位置と関係が薄いので使わない。「ボトル下部の凹凸」に絞る |
| 参考画像 | 8コマ | センサ出力をアナログのノイズ波形で描いている | センサ出力はON/OFFの2値。「1本の間にON/OFFが2回」で描く |
| 参考画像 | 9コマ | KR-Qを「反射型」と表記。製品写真は実物の確認ができない描画。「反射光の変化に強いアルゴリズム」「豊富な実績」は公式資料で未確認 | 「透明体検出タイプ・回帰反射型」と表記。製品写真は公式画像（許諾後）に差し替える枠。未確認の性能表現は使わない |
| 参考画像 | 11コマ | 改善後「+0.1〜0.3%」は実測の根拠がない | 実測値がない間は「仮想データ（教育用）」と明記し、比較は記録した値だけ |
| 参考画像 | 12コマ | 実機デモの直後に「これなら安定してカウントできますね」と結論が出ている | 「実際のラインでも確かめたい」（P4最後の問いの推奨）につながる反応に変更 |
