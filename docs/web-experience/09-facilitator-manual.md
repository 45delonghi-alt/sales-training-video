# 09　進行役操作マニュアル（WEB参加・学生1〜5名）

## 1. しくみ

```
進行役のPC（?view=host）──┐
                          ├─ 配信サーバー（npm run experience:serve）── 状態をリアルタイムに配る（SSE）
学生1〜5名の端末（?view=join&session=コード）──┘
```

- 進行役が場面を進めると、学生全員の画面が切り替わる。映像は**学生それぞれの端末**で再生される（音もそれぞれ）。
- 学生は各自で選択・理由・提案・振り返りを入力する。**回答前に正解は出ない**。
- 回答を締め切ると、学生それぞれに**自分が選んだ選択肢の映像**（お客様の反応）が流れる。
- 解説の段階で、推奨と理由を表示。**2名以上**なら「A 1名／B 3名／C 1名」と選択理由（**名前なし**）を共有。**1名なら個別体験**として共有しない。個人の順位はつけない。
- 保存はサーバーのメモリだけ。個人情報は扱わない（表示名＝ニックネームと回答だけ）。サーバーを止めると消える。

## 2. 事前準備

1. 映像を書き出す：`npm run experience:render`（体験クリップ68本）
2. アプリを作る：`npm run experience:build`
3. 配信する：`npm run experience:serve`（ポートは環境変数 `PORT`。既定 4173）
4. **学生が外から入る場合は、インターネットからつながる場所で配信する**（社内サーバー・クラウドのVMなど。HTTPS推奨）。同じネットワーク内なら、会場PCで配信して `http://<PCのIP>:4173/` で入れる。
5. 進行役のブラウザで `/?view=host` を開く。

## 3. 当日の操作

| 手順 | 進行役の操作 | 学生の画面 |
|---|---|---|
| 1 | 「セッションを作成する」 | ― |
| 2 | 右の**参加URL**をチャット等で送る（QRコードも出る） | 表示名を入れて「参加する」（最大5名。6名目は満員と表示） |
| 3 | 右の参加者一覧で、全員が緑（接続中）になったのを確認 | 「参加中（n名）」 |
| 4 | 左の一覧の「導入動画」を押す（最初はこの場面） | 導入動画が流れ、3か所で止まって考える（各自「続きを見る」） |
| 5 | 「次へ」 | YOUR MISSION →以降、場面ごとに下の表 |

### 場面ごとの操作

| 場面 | 進行役のボタン | 見るところ |
|---|---|---|
| 映像（相談・データ・CLEARなど） | 全員が「視聴済み」になったら「次へ」 | 参加者一覧の「視聴済み」 |
| 問い（A/B/C） | ①回答を受付（自動）→ 全員回答したら ②締め切り → 全員が映像を見たら ③解説 → 「次へ」 | 選択肢ごとの人数と、名前つきの理由（進行役だけに見える）。理由を1〜2名に話してもらう |
| 30秒の提案 | 入力中 → 全員提出したら「全員に共有」→ 1〜2名に読み上げてもらう | 4つの要素がそろっているか。「必ず直る」と言い切っていないか |
| 比較デモ | 実機で記録したら「実測として学生に表示する」 | 入力しなければ「仮想データ（教育用）」と明記して表示される |
| P4-Q3のあと | 実測が基準に届かなかったときだけ「基準に届かなかったとき」 | ― |
| 振り返り | 入力中 → 「全員に共有」 | 提出状況 |

### 困ったとき

| 状況 | 対応 |
|---|---|
| 学生の通信が切れた | 自動で再接続する。直らなければ、同じURLを開き直してもらう（同じ人として戻り、回答も残る） |
| 学生が別の端末で入り直した | 新しい参加者として入る（5名を超える場合は、右の一覧の×で古い方を取り消す） |
| 映像が再生されない | 学生の画面の「▶ 再生する」を押してもらう（ブラウザの自動再生の制限） |
| 時間が押している | 問いの「解説」の段階で、ほかの選択肢の映像は見せずに次へ。比較デモは1条件（揺れ）だけにする |
| 最初からやり直す | 「セッションの操作」→「回答を消して最初から」 |
