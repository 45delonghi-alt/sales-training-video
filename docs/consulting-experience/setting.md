実写の撮影・CG・画像生成は、この設定に合わせます。すべての分岐映像が「同じ工場で、同じ人たちに起きていること」に見えるようにするための資料です。
シナリオの正本は `src/experience/data/phases.json`、人物は `src/experience/data/characters.json` です。

## 3. センサの設置（全カット共通）

- センサは **透明体検出用の回帰反射型センサ（投光・受光一体）**。
- センサを**コンベアの片側に横向き**で取り付け、**反射板を反対側に、同じ高さで正対**させる。
- 検出位置は **ボトルの下部（側面から）**。キャップや上部を検出位置にしない。
- 光の経路：**センサ → ボトル下部 → 反射板 → 同じセンサへ戻る**。
- **反射板は光を出さず、受けもしない**（光を戻すだけ）。光を出して受けるのはセンサ本体。
- **透過型（投光器と受光器が別体）と混同しない**。反対側に描くのは受光器ではなく反射板。
- 光の線（赤）は**説明用の表現**。実製品の光の色・見え方は公式仕様で確認する。

```
上から見た図
          奥  ┌──────────────── 反射板（光を戻すだけ）──────────┐
              │                     ▲ │                          │
  ガイドレール │═════════════════════│═│══════════════════════════│
              │   ○    ○    ○    ○ │ │ ○    ○    ○             │ → 流れ
  ガイドレール │═════════════════════│═│══════════════════════════│
              │                     │ ▼                          │
          手前 └──── センサ（投光・受光一体、横向き）─────────────┘
                     光：センサ → ボトル → 反射板 → 同じセンサ

横から見た図
        ┌─┐ キャップ（ここは検出しない）
        │ │
       ┌┘ └┐
       │   │
  センサ▶───────▶反射板   ← 検出位置はボトルの下部。センサと反射板は同じ高さ
       └───┘
  ═══════════ コンベア
```

- カメラA：手前から水平。カメラB：真上。カメラC：高所から全景。

### 服装のルール

- 工場内にいる人は全員、**清潔な作業服と衛生帽**を着用する。**スーツ・アクセサリー（指輪・腕時計・ピアスなど）はなし**。
- OPTEX-FA の森さん・中田さんも、訪問時は**工場の作業服と衛生帽**を着用する（来訪者バッジで区別）。
- 髪は衛生帽の中に収める。

### 一貫性のルール

- 同じ人物は、全カットで同じ顔・同じ服装にする。変えるのは表情と動作だけ（考え込む／前向き／お願いする／不安そう／素っ気ない／心配する／うなずく）。
- 選択肢への返答は、質問の内容に合う人が答える（設備のことは佐藤さん、数量の照合や品質のことは高橋さん）。

## 6. 色と表示
