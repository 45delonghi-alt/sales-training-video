# キャラクター・工場レイアウト設定資料

実写の撮影・CGの制作は、この設定に合わせる。すべての分岐映像が「同じ工場で起きていること」に見えるようにするための資料。

## 1. 舞台：飲料工場（教育用の架空設定）

| 項目 | 設定 |
|---|---|
| 工場 | 国内の飲料メーカーの工場（社名は出さない） |
| ライン | **LINE 03**（PETボトル飲料の充填後、箱詰め前のカウント工程） |
| 製品 | 500mL相当の透明PETボトル。胴にリブ（凹凸）、ラベル付き、中身入り |
| 流れ | 画面の左から右へ。通常は一定の間隔。ときどきボトルが寄り、揺れる（＝流れが乱れる） |
| 計数 | 光電センサの出力をPLCで数える。表示は「実際の本数／センサのカウント」（HUD） |
| 困りごと | 実際の本数よりカウントが多くなることがある（週に数回）。そのたびにラインを止めて数え直す |

## 2. 設備配置（上から見た図）

```
          奥  ┌──────────────── 反射板 ────────────────┐
              │                    ▲│                    │
  ガイドレール │════════════════════ │ ═══════════════════│
              │   ○    ○    ○   ○ │  ○    ○    ○      │ → 流れ
  ガイドレール │════════════════════ │ ═══════════════════│
              │                    │▼                    │
          手前 └────────────── 光電センサ ───────────────┘
                                （回帰反射型。光はコンベアを横切って往復）
```

- センサの高さ：ボトルの胴（下から約1/2）。
- カメラA：手前から水平。カメラB：真上。カメラC：高所から全景。

## 3. 人物

| 役 | 設定 | 見た目 | 話し方 |
|---|---|---|---|
| お客様 | 飲料工場 設備課の担当者（30〜40代） | 作業着・帽子・名札「設備課」。現場をよく知る実務担当 | 丁寧だが率直。困っていることははっきり言う。売り込みには慎重 |
| 設備担当者 | お客様の同僚（STEP4 で登場） | 同じ作業着 | — |
| 作業者 | ラインの作業者（2名） | 作業着・帽子 | セリフなし |
| 営業担当（学生） | OPTEX-FA の営業。画面には映らない（一人称） | — | 選択肢の言葉で話す |

**一貫性のルール**：お客様役は全カットで同じ人・同じ服装にする。表情と動作だけを変える（考え込む／身を乗り出す／首をかしげる／ボトルを差し出す／心配する／反応が薄い／うなずく）。

## 4. 色と表示

- ブランドカラー：赤 #D7141E、白、黒 #141517（導入動画の赤 #E60012 との統一は確認中）。
- 光（ビーム）：赤の破線。透明ボトルは輪郭線＋淡い水色。
- 字幕：2行以内。お客様のセリフには「お客様」のラベル。強調語は赤。
- シミュレーション：画面右上に「シミュレーション　実測結果ではありません」を常に表示。
