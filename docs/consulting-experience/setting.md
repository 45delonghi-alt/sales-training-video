# 舞台・人物・世界観　設定資料

写真素材（画像生成・撮影）とアニメーションは、この設定に合わせます。すべての分岐映像が「同じ工場で、同じ人たちに起きていること」に見えるようにするための資料です。
シナリオの正本は `src/experience/data/phases.json`、人物は `src/experience/data/characters.json`、写真素材は `src/experience/data/plates.json`、センサ配置のマスター図は `src/experience/remotion/v3/Layout.tsx` です。

## 3. センサの扱い

### 既設センサ（他社製）

- お客様が今使っている、**他社製の回帰反射型光電センサ**。透明なボトル専用かどうかは、お客様も確認できていない。
- 今もPETボトルは検出できている。搬送の条件によって、信号が不安定になる**可能性**がある、という扱い。
- **メーカー名（OMRON・KEYENCE など）を出さない。原因と決めつけない。「不良」「欠陥」「劣っている」と言わない。**

### 提案するセンサ：OPTEX-FA KR-Qシリーズ

- **透明体検出タイプの回帰反射型センサ**。反射板（反射ミラー）を使う。
- 製品ページは optex-fa.jp に掲載されているとみられる（検索結果より。生産終了一覧の抜粋に KR-Q は見当たらない）。ただし**公式ページ本文は直接照合していない**。
- 候補型式：KR-Q50N（10〜500mm）／KR-Q150NW（0.01〜1.5m）／KR-Q300NW（0.01〜2.5m）、応答時間 0.7ms 以下。いずれも販売店掲載・検索抜粋の値で、**画面・セリフには出さない**（公式資料で照合してから）。
- 光源は公式抜粋（赤色LED）と販売店（赤外LED）で食い違う。詳細は [research/product-facts.md](research/product-facts.md)。
- 「他社より必ず優れている」とは言わない。違いは公式資料で確認し、実際のボトルで確かめる。

### 比較デモ

- 既設センサと KR-Qシリーズを、**同じボトル・同じ搬送速度・同じ設置の高さ（ボトル下部）**で比べる。
- 反射板と設定は、それぞれのセンサに合ったものを使う。
- 条件は 通常搬送／ボトルの揺れ／間隔の変化／検出高さの比較 の4つ。詳細は [demo-checklist.md](demo-checklist.md)。

## 4. センサの設置（全カット共通・マスター図に従う）

- センサは **投光・受光一体**の回帰反射型（既設センサ・KR-Qシリーズとも）。
- センサは**コンベアの手前側に横向き**で取り付け、**反射板は奥側に、同じ高さで正対**させる。
- 検出位置は **ボトルの下部（底から約20%）**。キャップや肩を検出位置にしない。
- 光の経路：**センサ → ボトル下部 → 反射板 → 同じセンサへ戻る**（行きと戻りを分けて描く）。
- **反射板は光を出さず、受けもしない**（光を戻すだけ）。光を出して受けるのはセンサ本体。
- **透過型（投光器と受光器が別体）と混同しない**。奥側に描くのは受光器ではなく反射板。
- 赤い光の線は**説明用の表現**。実製品の光の色・見え方は公式仕様で確認する。

```
上から見た図（搬送方向：左 → 右）
     奥  ┌──────────── 反射板（光を戻すだけ）────────────┐
         │                    ▲ │                            │
         │   ○    ○    ○    ○│ │○    ○    ○               │ → 搬送方向
         │                    │ ▼                            │
   手前  └──── センサ（投光・受光一体、横向き）───────────────┘
              光：センサ → ボトル下部 → 反射板 → 同じセンサ

横から見た図
        ┌─┐ キャップ（ここは検出しない）
        │ │
       ┌┘ └┐
       │   │
  センサ▶───────▶反射板   ← 検出位置はボトル下部（底から約20%）。センサと反射板は同じ高さ
       └───┘
  ═══════════ コンベア
```

### 服装のルール

- 工場内にいる人は全員、**白い衛生帽**を着用する。**スーツ・アクセサリー（指輪・腕時計・ピアスなど）はなし**。
- お客様（佐藤さん・高橋さん）は**白い衛生作業服**。OPTEX-FA の森さん・中田さんは**淡いブルーグレーの作業ジャンパー**で、服の色でお客様と区別する。
- 髪は衛生帽の中に収める。

### 一貫性のルール

- 同じ人物は、全カットで同じ顔・同じ服装にする。基準は人物マスター画像（`plates.json` の `CAST`）。変えるのは表情と動作だけ。
- 選択肢への返答は、質問の内容に合う人が答える（設備のことは佐藤さん、数量の照合や品質のことは高橋さん）。

## 6. 写真素材

- 場面の背景は写真ベース（`plates.json`：場面画像 F01〜F18 と人物マスター CAST）。多くは生成待ち。

- 実在のメーカーのロゴ・製品名を写さない。KR-Qシリーズの製品画像は公式画像のみ（利用許諾が必要）。

## 8. 色と表示

- ブランドカラー：赤 #D7141E、白、黒 #141517（導入動画の赤 #E60012 との統一は確認中）。
- 光の線：赤の線（説明用の表現）。行きと戻りを区別して描く。透明ボトルは輪郭線＋淡い水色。
- 字幕：2行以内。話し手の名前（佐藤さん・高橋さん・森さん・中田さん）をラベルで表示。強調語は赤。
- シミュレーション・仮想検証：画面に「シミュレーション　実測結果ではありません」を常に表示。
- 架空データ：「研修用の架空データ」と表示。
- 結果の画面：「実測データ」「研修用シミュレーション」「期待する改善効果」を分けて表示する。実測していない改善後の数値は出さない。
