# 技術表現のルール

映像・セリフ・資料のすべてに適用する。`npm run experience:validate` が一部を機械的に検査する（下の「自動検査」）。表現ごとの確認状況は [technical-review.md](technical-review.md)。

## 1. センサの方式と配置

| 項目 | ルール | やってはいけないこと |
|---|---|---|
| 方式 | 透明体検出用の**回帰反射型**光電センサ（投光・受光一体） | 投光器と受光器が別体の**透過型**と混同する |
| センサの位置 | コンベアの**片側**に、**横向き**に取り付ける | 上から真下に向ける（導入動画の旧版の表現。修正済み） |
| 反射板の位置 | **反対側**に、センサと**同じ高さ**で**正対**させる | センサと反射板の位置を入れ替える／高さをずらす |
| 検出位置 | ボトルの**下部**（底から少し上）を**側面から** | キャップ・肩・上部を検出位置にする |
| 光の経路 | センサ → ボトルの下部 → 反射板 → **同じセンサ**に戻る | 反射板が光を出す・受けるように描く・話す |
| 光の描き方 | 行き（センサ→反射板）と戻り（反射板→センサ）を**分けて**描く。赤い線は**説明用の表現**と明記 | 実製品の光の色・見え方として断定する |

## 2. 誤カウントのデータ

| 項目 | ルール |
|---|---|
| 性質 | 常に**実際より多い**（過剰カウント）。少なく数える・検出漏れの話にすり替えない |
| 数値 | 実際10,000本に対し、10,060（+0.6%）／10,300（+3.0%）／10,050（+0.5%）／10,080（+0.8%） |
| 言い方 | 「通常は+0.5〜0.8%、多いときに+3%くらい」。**毎週3%とは言わない** |
| 表示 | 数値の出る画面には「研修用の架空データ」と明記 |
| 頻度の演出 | 映像でも「ときどき・不規則に」起きる。毎回・規則的に誤カウントさせない |

## 3. 原因の扱い

- 原因は体験の中で**確定させない**。「可能性があります」「まだ分かりません」と言う。
- 調査では、**センサの出力**（1本の通過で何回切り替わったか）と**PLCのカウント**（信号をどう数えたか）を分けて確認する。
- 既設センサのメーカー・機種を原因と決めつけない。他社製品を悪く言わない。

## 4. 製品・画像

| 項目 | ルール |
|---|---|
| OPTEX-FA 製品 | **公式画像のみ**使用（許諾確認後に配置）。候補は KR-Q シリーズ等。現行品かどうか・型式・仕様は公式情報で確認するまで「確認中」と書く |
| 既設センサ | OMRON または KEYENCE の公式画像を使ってよいが、型式と用途（透明体用・回帰反射型）を確認し、許諾を得てから。メーカー名を原因として扱わない |
| ロゴ・型式 | AI で生成しない。架空の型式を作らない。カタログ・チラシ類は「メーカー名・型式は表示していません」と明記 |

## 5. 結果・シミュレーション

- 実測値・成功結果を**作らない**。映像のデモは「シミュレーション（見方の説明）」と表示し、1本目以降の結果は見せない。
- 実機デモの判定は、進行役が記録した実測だけで行う（通過本数＝カウント値、かつ出力の切り替わりなし）。
- お客様の「この条件では正しく数えられましたね…」は、**基準を満たした場合の想定シナリオ**としてだけ使う（P4-Q3 は実測が基準を満たしたときだけ出る）。

## 6. 人物・現場

- 工場内の全員が、清潔な作業服と衛生帽を着用（髪と耳を覆う）。スーツ・アクセサリーなし。OPTEX-FA の社員も、訪問時は工場の作業服と衛生帽を着る。
- お客様は30〜40代の男女（設備課・佐藤さん、品質管理課・高橋さん）。先輩社員（森さん・中田さん）は必要なときだけ登場し、答えを言わない。

## 7. 自動検査（`npm run experience:validate`）

| 検査 | 内容 |
|---|---|
| 過剰カウント | 「少なくカウント」「検出漏れが原因」など、少なく数える方向の言い回しがないか |
| 反射板 | 「反射板が光を出す／受ける」などの言い回しがないか |
| 数値 | 「0.5〜0.8%」と「3%」の両方が台本に出てくるか |
| 分岐 | 選択肢ごとに別の映像か、問いの背景映像と重複しないか、行き止まりがないか |
| 時間 | フェーズの合計が60分か |
