# 体験アプリ 操作マニュアル

## 1. 起動

```bash
npm run experience:build   # dist/experience/ に書き出す（素材を差し替えたら毎回）
npm run experience:serve   # http://localhost:4173/ で配信
```

| 画面 | 開き方 | 使う人 |
|---|---|---|
| 操作画面 | `http://localhost:4173/` | 進行役（手元のPC） |
| 投影用ウィンドウ | 進行役パネル「投影用ウィンドウを開く」（`?view=projector`） | プロジェクタに出す |
| スマートフォン回答 | 投影画面に出るURL（`?view=vote&session=コード`） | 学生（同じネットワークの端末） |

- 配信サーバーを起動すると、ターミナルにスマートフォン用のURL（会場PCのネットワーク上の住所）が出る。
- 2次元コードの表示機能はない（ライブラリを追加していないため）。URLとコードを投影し、学生に入力してもらう。

## 2. 画面の見方

```
┌ 上部バー：フェーズ（導入・聞く・考える・課題を見つける・提案する・振り返り）／経過時間／フェーズ残り時間
│           音量・字幕ON/OFF・全画面・学生画面⇔進行役モード
├ 中央：映像・問い・結果
├ 下部：← 戻る ／ 場面名・番号 ／ 次へ →
└ 右側：学生画面＝「これまでに分かったこと」「まだ分からないこと」
         進行役モード＝進行役パネル
```

## 3. 問いの操作

1. 問いが出ると、考える時間のタイマーが回る（選択肢はまだ出ない）。
2. 「選択肢を表示する」→ A/B/C を選ぶと、その選択肢専用の映像が流れる。
3. 映像のあと、結果画面に **営業のセリフ／お客様の回答／分かったこと／まだ分からないこと／ポイント／推奨と理由** が出る。
4. 「選び直す」でほかの選択肢を試せる（試した順は記録に残る）。
5. 「💡 先輩のヒントを見る」で、先輩社員のヒントを出せる。用語メモは押すと開く。

## 4. 進行役パネル

| 項目 | できること |
|---|---|
| いまの場面 | 進行メモ、推奨と理由（学生には回答後に表示）、ヒントの表示、**ほかの選択肢の結果を表示** |
| 投影・再生 | 投影用ウィンドウを開く、再生・一時停止、素材の状態表示（仮映像・CGなど）のON/OFF |
| スマートフォン回答 | 受付開始、コードとURL、集計（人数・理由）、集計を投影、最多の選択肢で進める、受付終了 |
| 選択結果 | 各問いで選んだ順、実機デモの判定 |
| 場面へ移動 | どの場面にも直接移動 |
| 記録 | JSONで保存・コピー、最初からやり直す |

キーボード：Alt + → 次へ ／ Alt + ← 戻る ／ Space 再生・一時停止。

## 5. 実機デモ画面

| 表示の切り替え | 中身 |
|---|---|
| シミュレーション | 見方の説明（1本目だけ。結果は見せない） |
| 実機（ライブ） | 実機を直接見せる。画面には条件と記録した数値だけ出す |
| 実機の動画 | 事前に撮った動画ファイルを選んで再生（このブラウザだけ。保存はしない） |

- 比較デモは4条件（通常搬送・ボトルの揺れ・間隔の変化・検出高さの比較）。再生前に「結果を見る前に、予想しよう」が出る。
- 記録は**センサごと**（既設センサ／KR-Qシリーズ）に：通過させた本数／センサの出力回数（表示灯・出力の記録）／カウント値（PLC）／1本の通過中に出力が何度も切り替わったか。
- 判定：本数・出力回数・カウント値がすべて一致し、切り替わりがなければ「基準を満たした」。過剰率（(カウント−本数)÷本数）も出る。出力回数とカウント値を分けて記録するので、数が増えた場所（センサ側かPLC側か）を切り分けられる。
- 「結果の比較」画面に、記録した値だけがセンサごと・条件ごとに並ぶ（未記録は「未記録」。数値を作らない）。結果は「1. 実測データ／2. 研修用シミュレーション／3. 期待する効果」に分けて表示する。
- P4-Q3 は、それまでのすべての比較デモで **KR-Qシリーズ**の記録が基準を満たしたときだけ出る。満たさない・未記録なら、追加調査の場面へ進む案内が出る。

## 6. 記録と保存

- 進行状況と記録は、このブラウザに自動で保存される（再読み込みしても続きから）。
- 「記録を保存（JSON）」で、選択・理由・実測・振り返りメモをファイルに保存できる。
- スマートフォン回答の集計は配信サーバーのメモリにだけあり、サーバーを止めると消える。必要なら集計画面を撮影しておく。
