## 時間が押したときの調整

| 状況 | 調整 |
|---|---|
| PHASE 1〜3 が押した | 「選び直す」での比較をやめ、進行役の「ほかの選択肢の結果を表示」で一度に見せる |
| 実機デモが押した | 悪条件は4つのうち2つ（揺れ・間隔）に絞る。P4-Q4 は全条件の記録が前提なので、未実施の条件は「追加検証が必要」として扱い、成功扱いにしない |
| 実測が基準に届かない | P4-Q3／P4-Q4 は出ず、「結果が基準に届かなかったとき」へ進む（進行役が案内する） |
| 振り返りが押した | Q1・Q3 を口頭で、Q2・Q4 はワークシートの宿題にする |
