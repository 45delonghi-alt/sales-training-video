# 制作方針・全体構成（v3）

## 1. 結論

- タイトルは **「YOUR MISSION ペットボトルの誤カウントを解決せよ！」**（OPTEX-FA CONSULTING SALES EXPERIENCE）。
- 物語：飲料工場の既設設備では、**他社製の回帰反射型光電センサ**で透明PETボトルを数えている。実際より**多く**数えることがある。学生は OPTEX-FA の営業担当として、**聞く → 考える → 課題を見つける → 提案する**の4つのプロセスで原因と課題を整理し、**OPTEX-FA KR-Qシリーズ（透明体検出タイプ）**を提案して、**既設センサと同じ条件で実機比較**する。
- 60分＝導入5／聞く10／考える10／課題を見つける10／提案する（比較デモ）15／振り返り10。問いは9つ（27の選択肢）。
- 見た目は添付のインフォグラフィック（12シーン）を全編の基準にする：**実写風の工場写真＋黒帯の見出し＋白い説明カード＋赤の強調**。線画の人物は使わない。
- 声は**音読さん**で収録する。トークスクリプト（[talk-script.md](talk-script.md)）を先に確定し、収録した音声の長さに合わせて映像・字幕のタイミングが自動で決まる。

## 3. 設計の考え方

| 狙い | 仕掛け | なぜそうするか |
|---|---|---|
| 質問で原因が見えてくる | 問いごとに専用の映像と回答。「分かったこと／まだ分からないこと」を並べる | 次に何を聞けばよいかを、自分で考えられる |
| 本当の困りごとが分かる | 「何とか対応できている」の裏を聞く → 確認・ライン停止 → 安定した生産 | お客様が欲しいのはセンサではなく安定した生産 |
| 技術で解決を目指す | 光の往復の配置図、仮想検証（1本なのに2回）、同じ条件での比較 | 技術を「確かめ方」とセットで理解する |
| 正解当てにしない | 推奨は回答後に理由と表示。推奨なしの問いもある | 選択しながら進むので、営業未経験でも体験しやすい |
| 誠実さ | 実測・シミュレーション・期待効果を分ける。改善後の数値は実測まで出さない。他社製品を欠陥扱いしない | 研修で「数字を作る」ことを教えない |

## 4. 技術表現のルール（要約）

詳細は [technical-rules.md](technical-rules.md)。

- センサは**回帰反射型**（投光・受光一体）。センサはコンベアの片側で横向き、反射板は反対側の**同じ高さ**で正対。検出位置は**ボトルの下部**。光は「センサ → ボトル下部 → 反射板 → 同じセンサ」。反射板は光を出さず、受けもしない。赤い線は説明用の表現。
- 既設は**他社製の回帰反射型**（透明体専用とは限らない）。メーカー・型式は確認できるまで表示しない。
- 提案は **OPTEX-FA KR-Qシリーズ（透明体検出タイプ）**。製品画像は公式画像のみ。型式・仕様は公式資料で確認してから表示する。「他社製品より必ず優れている」とは言わない。
- データは**研修用の架空データ**：10,060／10,300／10,050／10,080本（通常+0.5〜0.8%、最大+3.0%）。常に過剰カウント。
