### 全分岐テストで確かめたこと

- **10の問い × A/B/C の30分岐すべて**で、選んだ選択肢の専用映像が再生され、お客様の回答・分かったこと・まだ分からないことがデータと一致する。
- 考える時間と選択肢の表示中は、学生画面に「推奨」を出さない。回答後は、推奨（推奨なしの問いは「推奨：なし」）と理由を出す。
- 先輩のヒントを表示できる。学生側の結果画面に比較ボタンは出ず、進行役パネルからほかの選択肢の結果を表示できる。
- 実機デモ：再生前に「予想しよう」を出す。通過本数・センサの出力回数・カウント値・切り替わりの有無を記録すると判定が出る（テスト用の入力。実測値ではない）。
- **基準未達の分岐**：通常条件で「切り替わりあり」→ P4-Q3 は出ず、追加調査へ進む。**未記録**のときは記録を促す。
- エンディングのあとに終了画面（選んだ選択肢の一覧）が出る。
- 再読み込みしても場面と記録が残る。戻る・場面へ移動・最初からやり直す。
- 学生画面に進行役パネルを出さない。「分かったこと」がたまり、「まだ分からないこと」を出す。
- 投影用ウィンドウが進行に追従し、操作ボタンを出さない。
- **スマートフォン回答**：受付開始でコードとURLを投影 → 3端末（スマートフォンの画面サイズ）から回答 → 進行役の集計が B 2人・A 1人 → 集計を投影 → 「最多のBで進める」で映像へ → 端末側は受付終了を表示。端末側には集計を返さない。
- ページのエラー 0、存在しないファイルの読み込み（404）0。

## 3. 制作中に見つけて直したこと

| 問題 | 対応 |
|---|---|
| 導入動画のセンサが上から真下を向いていた（技術ルールと不一致） | 片側・横向き・ボトル下部に修正し、反射板を追加。再書き出し |
| 導入動画の誤カウントが5本に2本と多すぎた | 不規則に、ときどきに変更 |
| 実機デモの判定が「本数＝カウント値」だけで、センサとPLCを切り分けられなかった | センサの出力回数の記録欄を追加し、3つの数がそろったときだけ合格 |
| 一括書き出しでブラウザが途中終了（Target closed） | 並列数を下げ、未書き出しの素材だけを1本ずつ書き出し直した。全48本を確認 |
