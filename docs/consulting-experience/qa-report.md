### 全分岐テストで確かめたこと

- 7つの問い × A/B/C の **21分岐すべて**で、選んだ選択肢の映像が再生される。お客様の回答・分かったことが、その選択肢のデータと一致する。
- 考える時間には選択肢を出さない。「解説を表示」を押すまで、学生画面に推奨（おすすめ）を出さない。
- 比較画面に、3つの選択肢それぞれで分かることが出る。
- 実機デモの記録（通過本数・カウント値・出力の多重切り替わり）から判定が出る。
- **基準未達の分岐**：通常条件で「切り替わりあり」と記録すると、STEP3 の問いは出ず「追加調査」へ進む。**未記録**のときは記録を促す。
- 戻る・場面へ移動・最初からやり直す。再読み込みしても、場面と記録が残る。
- 学生画面に進行役パネルを出さない。「分かったこと」がたまっていく。
- 投影用ウィンドウが進行役の操作に追従し、操作ボタンを出さない。
- ページのエラー 0、存在しないファイルの読み込み（404）0。

## 3. チェックリスト（マスタープロンプト 23章）

### 教育品質
- [x] 営業未経験でも理解できる（専門用語は「回帰反射型」「PLC」程度。チャタリングという語は使わない）
- [x] 各フェーズの目的が明確（上部バーと右パネルに目的を表示）
- [x] 質問の意図が理解できる（回答後に「ポイント」と、他の選択肢との比較）
- [x] 学生自身が考える時間がある（問いごとに30〜60秒。選択肢はその後に表示）
- [x] 解説が長すぎない（解説クリップは最長約40秒）
- [x] 実機デモまで物語がつながる（現象 → 条件 → 業務への影響 → 提案 → 検証）

- [ ] **人物に不自然な変化がない** → 線画の仮素材。実写素材待ち
