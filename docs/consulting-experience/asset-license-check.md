## 4. CG の表現（現在の実装）

- 線画（白・黒・赤）。センサは片側に横向き、反射板は反対側に同じ高さで正対、検出位置はボトルの下部。
- 光は赤の破線で、**行き（センサ→反射板）と戻り（反射板→センサ）を分けて**描く。「※ 光の線は説明用の表現です」を表示。
- 透明ボトルは「輪郭線＋淡い水色」。光はボトルを通り抜け、通り方がわずかに変化する。
- シミュレーションには常に「シミュレーション　実測結果ではありません」を表示。悪条件の結果は描かない（「この先は、実機で確かめる」）。
- 製品の外観は描かない。公式画像の枠に「公式製品画像　許諾を確認後に配置」と表示。
- 人物は全員、清潔な作業服と衛生帽（髪と耳を覆う）。
