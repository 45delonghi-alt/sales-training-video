# 進行役マニュアル

画面の操作は [app-manual.md](app-manual.md)、時間配分は [schedule.md](schedule.md)、実機の準備は [demo-checklist.md](demo-checklist.md)。

## 1. 進行役の役割

- 答えを教えるのではなく、**学生が自分で考えて選ぶ時間**を守る。
- 推奨以外を選んだ学生を否定しない。「その質問で何が分かった？　まだ分からないことは？」と、次の一手を考えさせる。
- 実機デモでは、**記録した事実だけ**を扱う。結果を作ったり、成功したように言い換えたりしない。

## 2. 事前準備（前日まで）

| 誰が | 何を | 確認の基準 |
|---|---|---|
| 進行役 | 会場PCで `npm run experience:build` → `npm run experience:serve` | ブラウザで最初の画面が出る |
| 進行役 | プロジェクタに「投影用ウィンドウ」を出し、音が出るか確認 | 導入動画の音声が会場の後ろまで聞こえる |
| 進行役 | スマートフォン回答を使う場合、会場Wi-Fiで学生の端末から参加URLが開けるか確認 | 試しに1台で回答し、集計に出る |
| 技術担当 | 実機デモの準備（[demo-checklist.md](demo-checklist.md)） | 通常条件で一度通しておく（本番の記録には使わない） |
| 進行役 | ワークシート（[worksheet.md](worksheet.md)）と記録シート（[demo-record-sheet.md](demo-record-sheet.md)）を印刷 | 人数分＋予備 |

## 3. 回答の集め方（2つの方式）

| 方式 | 使う場面 | 進め方 |
|---|---|---|
| 第1段階：1画面投影 | 標準 | 学生は挙手・グループで話し合い → 進行役が多数の選択肢をクリック |
| 第2段階：スマートフォン回答 | 人数が多い／全員の意見を見たい | 進行役パネル「回答の受付を始める」→ 投影画面のURLとコードで学生が参加 → 「集計を投影」→「最多の○で進める」 |

スマートフォン回答は、配信サーバー（`npm run experience:serve`）で開いたときだけ使える。回答はサーバーのメモリに一時保存され、サーバーを止めると消える。名前などの個人情報は集めない。

## 4. フェーズごとの進め方

### 導入（5分）
- 導入動画は3か所で自動的に止まる（各15秒）。答えは言わせっぱなしでよい。正解はこのあとの体験で見つける。
- 「YOUR MISSION」の画面で「ここからは、皆さんが営業担当です」と一言添える。

### PHASE 1 聞く（10分）
- P1-Q1：「専門知識がなくても大丈夫」と伝える。困ったら「先輩のヒント」を表示。
- 回答後の「分かったこと／まだ分からないこと」を読み上げ、次の問い（P1-Q2）につなぐ。
- 数値は**研修用の架空データ**（通常+0.5〜0.8%、最大+3.0%）。毎週3%ではないことに注意。

### PHASE 2 考える（10分）
- P2-Q1 は**推奨なし**。「どれも原因の候補。どれから確かめる？」と優先順位を話し合わせる。
- 「解説：透明なボトルと光」は途中で止まる。「戻ってくる光はどうなる？」を予想させてから再開。
- 「チャタリング」などの専門用語は覚えなくてよい。「1本なのに2回数えることがありうる」が伝われば十分。
- センサの出力とPLCのカウントを**分けて**確かめる、を強調する。

### PHASE 3 課題を見つける（10分）
- 「誤カウントを直すこと」がゴールではなく、「正確な数量管理と確認作業の負担を減らすこと」が本当の課題。
- 学生が「センサを売る」発想に戻ったら、「お客様が本当に困っているのは何？」と問い返す。

### PHASE 4 提案する・実機デモ（15分）
- P4-Q1 → 準備 → P4-Q2 で「何を確かめるか」を決めてから実機へ。
- 各デモの前に、画面の「予想しよう」を学生に考えさせる。
- 実機の結果は、進行役パネルではなく**実機デモ画面の右側**に記録する（通過本数・センサの出力回数・カウント値・出力の切り替わり）。
- **基準を満たしたときだけ** P4-Q3／P4-Q4 が出る。満たさない・未記録のときは「追加調査の場面へ進む」を選ぶ。
- シミュレーション映像は「見方の説明」。実測の代わりにしない。

### 振り返り（10分）
- Q1〜Q4 を各2分。タイマーは画面で計れる。出た意見は進行役がメモ欄に入力（記録に残る）。
- 最後のメッセージ → エンディング → 終了画面（選んだ選択肢の一覧）で締める。

## 5. 困ったとき

| 状況 | 対応 |
|---|---|
| 音が出ない | 最初に「クリックして投影を開始」を押したか確認。手元の音量と投影用ウィンドウ側の音量も確認 |
| 映像が止まった・飛ばしたい | 「回答へ進む ⏭」または進行役パネルの再生・一時停止 |
| 場面を間違えた | 「← 戻る」、または進行役パネルの「場面へ移動」 |
| 実機が動かない | 実機デモ画面で「実機の動画」に切り替え、事前に撮った実機の動画を再生（撮影日と条件を口頭で伝える）。記録は空欄のまま、追加調査の場面へ |
| スマートフォン回答がつながらない | 第1段階（挙手）に切り替える。進行には影響しない |
| やり直したい | 進行役パネルの「最初からやり直す…」（記録が消えるので、先に「記録を保存」） |

## 6. 終了後

- 進行役パネルの「記録を保存（JSON）」で、選択・理由・実測・振り返りメモを保存する。
- 実機デモの記録シートと合わせて、次回の改善に使う（どの問いで迷ったか、どの条件で基準に届かなかったか）。
