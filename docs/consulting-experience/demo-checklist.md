# 実機デモ　準備チェックリスト

## 前週まで

- [ ] 使用するセンサの**シリーズ・型式を確定**し、現行品であることを公式資料で確認した（型式：＿＿＿＿＿＿＿＿）
- [ ] 取扱説明書で、検出距離・設置条件・反射板の種類を確認した
- [ ] 合格基準を設備担当と決めた（通常条件：＿＿＿本流して差0、出力の多重切り替わりなし）
- [ ] 悪条件の範囲を決めた（実際のラインで起こりうる範囲に限る）
  - 位置ずれ：手前・奥に ＿＿ mm まで
  - 間隔：最小 ＿＿ mm（接触させるか：する・しない）
  - 向き：ラベル・凹凸の向きを ＿＿ 通り
- [ ] 実物に近い透明PETボトルを用意した（中身入り・ラベル付き：＿＿本）
- [ ] 本番と同じ条件でリハーサルし、結果を記録した（**成功するかどうかを事前に知っておく**。本番で結果を作らないため）

## 当日（開始30分前）

- [ ] 検証台（小型コンベア、またはボトルを手で流すガイド）を設置した
- [ ] センサ・反射板の取付と光軸を調整した。レンズと反射板を清掃した（汚れは誤検出の原因）
- [ ] 検出表示（表示灯）が、学生から見える向きになっている（または書画カメラで投影）
- [ ] カウンター／PLC を接続し、0 にリセットした
- [ ] 配線を確認した。ノイズ源（モーター・インバータ）から離した
- [ ] アプリの実機デモ画面で「実機（ライブ）」に切り替え、記録の入力欄が使えることを確認した
- [ ] 予備のボトル・反射板・ケーブルを用意した

## デモ中

- [ ] 流す前に、検証項目と合格基準を読み上げた
- [ ] 本数を数える担当（学生1名）を決めた
- [ ] 各条件の結果を、その場でアプリに入力した（通過本数・カウント値・出力の多重切り替わり）
- [ ] 基準を満たさない結果も、そのまま記録した
