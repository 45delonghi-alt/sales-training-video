## Scene 1　工場で誤カウント発生

**ねらい**：何が起きたのか分からない

### 導入動画：コンサルティング営業とは（導入・MISSION理解）

既存の導入動画（約4分30秒）。途中で止めて考えさせるポイント：

- 「営業である皆さんは、お客様に何を確認しますか？」（ワークシートに1つ書いてから、続きを見よう）
- 「誤カウントを放っておくと、現場では何が起きると思う？」（30秒、となりの人と話してみよう）
- 「今回のお客様のボトルは「透明」。どの方式が気になる？」（ここまでの方式から1つ選んで、理由を考えよう）
- 「方式はいくつもある。今回のお客様には、どれが合いそう？」（まだ答えは出さなくてOK。理由を1つ考えよう）

### お客様からの相談（Phase1 現状確認）

#### 映像　`p1-situation`（約14.4秒）

- **映像**：飲料工場 LINE 03。透明PETボトルがコンベアを流れ、光電センサでカウント。右上の表示で「実際の本数」より「センサのカウント」が1多くなる。
- **カメラ**：ライン正面の全景（カメラA）→ 誤カウントの瞬間にセンサへズームイン。
- **動き**：ボトルが等間隔で流れる → 1本の通過でカウントが2増え、そのボトルが赤く光る → センサへ寄る。お客様の相談の間は、右下に困った表情の小窓。
- **音声・字幕**：
  - 2.5秒〜 お客様「最近、センサのカウントが合わないことがあるんです。」
  - 7.5秒〜 お客様「実際より多くカウントされることがあって……何とかできませんか？」

### 最初に何を確認する？（Phase1 現状確認）

お客様：「実際より多くカウントされることがあるんです。」

**問い**：営業として、最初に何を確認しますか？

**操作**：考える時間（60秒）→ 選択肢を表示 → 選択 → 選んだ選択肢の映像 → お客様の反応 → 新しく分かったこと → 比較・解説

#### 選択肢 A：「今、どのメーカーのセンサをお使いですか？」　`p1-q1-a`（約9.5秒）

- **映像**：既設センサにカメラが寄る。本体の外観、取付金具、反射板への向き、型式ラベル（読み取れない）。メーカーロゴは表示しない。
- **カメラ**：一人称で近づく（カメラA→センサ寄り）。ラベルでいったん止まる。
- **動き**：ズームイン → 型式ラベルにフォーカス枠 → 「型式：確認中」。
- **音声・字幕**：
  - 3.5秒〜 お客様「メーカーは分かりますが、型式はすぐには分かりません。」

  → 新しく分かったこと：既設センサの型式は、すぐには分からない（後で確認が必要）

#### 選択肢 B（推奨）：「どんなときに、どのくらい多くカウントされますか？」　`p1-q1-b`（約13.5秒）

- **映像**：通常運転のコンベア → ボトルの流れが乱れる（間隔が詰まり、位置がずれる）→ その場面でカウント表示が実際より増える。
- **カメラ**：少し引いたライン正面 → 流れが乱れ始めたらスローモーションでセンサへズームイン。
- **動き**：前半：正常にカウント → 後半：ボトルが寄り、揺れる → カウント+1の差が出る。
- **音声・字幕**：
  - 6.5秒〜 お客様「常にではありません。ボトルの流れが乱れたときに起こる気がします。」

  → 新しく分かったこと：誤カウントは常にではなく、ボトルの流れが乱れたときに起こるようだ

#### 選択肢 C：「新しいセンサへの交換は考えていますか？」　`p1-q1-c`（約7.0秒）

- **映像**：お客様が腕を組んで考え込む。背景にライン。
- **カメラ**：営業担当の一人称。お客様を正面からバストショット。

## Scene 4　光の仕組みをCGで解説

**ねらい**：OPTEX-FAのセンシング技術に興味を持つ

### 解説：透明なボトルと光（Phase2 原因の深掘り）

#### 映像　`p2-light`（約38.2秒）

- **映像**：左：3D CG（回帰反射型。手前にセンサ、奥に反射板。光がコンベアを横切って往復）。不透明なモノは光を遮り、透明なボトルは光を通す。その場の受光量と出力ON/OFFを表示。右：受光量のグラフ（模式図）。透明ボトルはわずかに減り、曲面で2回くぼむ → 出力が2回ON。
- **カメラ**：3D：カメラがゆっくり回り込む（オービット）。右は2Dグラフ。
- **動き**：不透明なモノで原理 → 「考えよう」で一時停止（透明なボトルだとどうなる？）→ 透明ボトルに切り替え → 受光量が基準付近を行き来 → 出力が2回ON → 「必ず誤検出するわけではない」。
- **音声・字幕**：
  - 0.8秒〜 ナレーション「回帰反射型は、反射板から戻ってくる光が遮られたかどうかで、モノを検出します。」
  - 8.1秒〜 ナレーション「透明なボトルは光をほとんど通すので、光の減り方がわずかです。」
  - 14.0秒〜 ナレーション「さらにボトルの曲面で光が曲がり、通過中に受光量が上下することがあります。」
  - 20.9秒〜 ナレーション「受光量が判定の基準付近を行き来すると、1本の通過で出力が何度も切り替わる可能性があります。」
  - 29.3秒〜 ナレーション「ただし、透明だから必ず誤検出するわけではありません。方式や設定、設置の条件しだいです。」

- **一時停止（考えよう）**：「透明なボトルが通ると、戻ってくる光はどうなると思う？」

### 解説：どこで数が増えている？（Phase2 原因の深掘り）

- **カメラ**：CG。左から右への信号の流れ。
- **動き**：信号パルスが流れる → 3か所に「？」 → 「切り分け」の文字。
- **音声・字幕**：
  - 0.8秒〜 ナレーション「数が増えているのは、センサの出力が何度も切り替わっているからでしょうか。」
  - 7.7秒〜 ナレーション「それとも、配線のノイズや、PLC側のカウント処理でしょうか。」
  - 13.6秒〜 ナレーション「原因を決めつけず、どこで数が増えているかを切り分けることが大切です。」

### OPTEX-FA の透明体検出センサ（Phase4 解決提案）
