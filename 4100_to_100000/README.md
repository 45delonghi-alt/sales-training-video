# 4100_TO_100000_CHALLENGE

**4,100円（JDI 100株）を5営業日で仮想資産100,000円にできるか？** を検証する、日本株の短期モメンタム研究システムです。

> ⚠ **リスク警告**
> 4,100円を5営業日で100,000円にするには約24.39倍が必要であり、通常の株式投資では極めて非現実的な目標です。
> 本システムは投資利益を保証するものではなく、ペーパートレードによる研究目的です。
> 画面上の「推奨」「BUY」等は研究モデル上のシグナルであり、投資助言ではありません。

## このシステムが「やらないこと」

| 項目 | 状態 |
|---|---|
| 証券会社（松井証券など）への実注文 | **実装していません** |
| 証券サイトへの自動ログイン・ブラウザ操作 | **実装していません** |
| ID・パスワード・APIキーの入力や保存 | **一切求めません／保存しません** |
| ナンピン・信用取引・レバレッジ・空売り | **禁止（設定で固定。変更すると起動しません）** |
| データ取得失敗時に架空データで分析 | **しません（エラーで停止）** |

`PAPER_TRADE = True` は固定値です。売買はすべて仮想（ペーパートレード）で、記録はPC内のCSVだけです。

## 2. 起動方法

### 毎朝の分析（JDI判定 → ランキング → TOP3 → 本日の判断）

```powershell
python main.py
```

- 東証の全上場銘柄（JPX公表の一覧、ETF/REIT等を除外）を取得するため **数分かかります**
- 急ぐときは監視リスト（`config.py` の `WATCHLIST`）だけで分析:

```powershell
python main.py --quick
```

### ダッシュボード（Streamlit）

```powershell
streamlit run dashboard.py
```

ブラウザが自動で開きます（開かない場合は http://localhost:8501 ）。
左の **「🔄 データ更新・分析を実行」** で最新データを取得します。ダッシュボードに注文ボタンはありません。

## 3. データ更新方法

| 方法 | 内容 |
|---|---|
| `python main.py` | 最新データを取得して分析（20分以内の再実行はキャッシュを使用） |
| `python main.py --no-cache` | キャッシュを使わず必ず再取得 |
| ダッシュボードの「データ更新」ボタン | 同上（キャッシュなし） |

- 取得元: **yfinance（Yahoo Finance）**。JDIだけ取得できない場合は stooq で再試行します
- データは **REALTIME ではありません**（約20分以上の遅延、または終値ベース）。画面に必ず表示されます
- 場中に実行した場合、当日の出来高は途中経過のため「出来高倍率」は小さめに出ます
- 自分で用意した実データを使う場合: `data/manual/6740.csv`（列: `Date,Open,High,Low,Close,Volume`）を置き、`config.py` の `DATA_PROVIDER = "csv"` に変更
- 分足（5分足/15分足/60分足）は ダッシュボードの「⑥ JDI分析」→「JDI 分足チャート」で取得できます

## 4. ランキング表示

`python main.py` の画面、またはダッシュボード「⑦ TOP10」で確認します。

| 列 | 意味 |
|---|---|
| 出来高倍率 | 当日出来高 ÷ 前日までの20日平均出来高 |
| 高値ブレイク | 「20日高値」or「前日高値」を終値で上抜けたか |
| Momentum Score | 下記の100点満点スコア（値上がりの保証ではない） |
| 100株必要金額 | 株価×100株（REALISTIC_MODE） |
| 購入可能/不可 | 現在の利用可能資金で買えるか |
| 判定 | BUY / WATCH / WAIT / 対象外 / 保有中 |

### Momentum Score（100点）

| 項目 | 配点 |
|---|---|
| 出来高急増（出来高倍率 1.0/1.5/2/3/5倍以上） | 最大20 |
| 20日高値ブレイク（直前2%以内でも一部加点） | 最大15 |
| 前日高値ブレイク | 最大10 |
| MA5 > MA20 | 10 |
| 短期モメンタム（前日比＋直近5日騰落率） | 最大15 |
| RSI（55〜70が最高点） | 最大10 |
| 売買代金 | 最大10 |
| ATR・値動き（ATR 3〜8%が最高点） | 最大10 |
| **減点** | RSI80超・流動性不足・当日高値から-7%以上の押し戻し・急騰後の崩れ |

### BUY条件（すべて満たす場合のみ）

- 出来高倍率 ≥ 2.0
- 終値 > 前日高値
- MA5 > MA20
- 50 ≤ RSI14 ≤ 78
- Momentum Score ≥ 70
- 当日上昇率 +25% 未満（+15%以上は「飛び乗り注意」警告）
- **購入可能（REALISTIC_MODE：株価 ≤ 利用可能資金÷100）**

条件を満たす銘柄がなければ **WAIT（本日は取引候補なし）** です。無理に毎日売買しません。

## 5. JDI 判定

毎回最初に 6740 ジャパンディスプレイを分析し、**HOLD / SELL / WATCH** のどれかを必ず表示します。

| 判定 | 条件 |
|---|---|
| SELL | 損切りライン到達（固定-5% または ATR基準）／利確+10%到達／トレーリングストップ（保有後高値から-5%）／トレンド崩れ（MA5<MA20・RSI<40・スコア<30） |
| HOLD | MA5>MA20 かつ スコア50以上 |
| WATCH | 上記以外（方向感が弱い） |

**重要：取得単価の設定**
含み損益は `config.py` の `JDI_COST_PRICE`（初期値41円）で計算します。実際の取得単価に書き換えてください。

### 乗換判定

購入可能な候補とスコア・乗換コスト（売りと買いのスリッページ）を比較し、スコア差が20点以上かつBUY判定なら「乗換候補」と表示します。
`python main.py backtest` を実行済みなら、**スコア帯別の過去リターン**から期待値差（参考値）も表示します。

## 6. 仮想売買（ペーパートレード）

| コマンド | 内容 |
|---|---|
| `python main.py paper-auto` | 分析し、ルール通りに仮想売買（保有がSELL判定なら仮想売却、ノーポジでBUY候補があれば仮想買付） |
| `python main.py paper-sell` | 保有銘柄を仮想売却 |
| `python main.py paper-buy 1234` | 指定銘柄を仮想買付（直近分析の上位/購入可能候補のみ、資金内・100株単位） |
| `python main.py status` | 仮想資産とチャレンジ進捗 |
| `python main.py reset` | 仮想ポートフォリオを初期状態（JDI 100株）に戻す |

約定価格 = 取得した遅延価格 ±1ティック（不利側）。手数料は松井証券の現物（1日50万円以下0円）を想定し0円です。

## 7. 5営業日チャレンジの進め方

| タイミング | やること |
|---|---|
| 毎朝（8:30〜9:00） | `python main.py` → JDI判定・ランキング・本日の判断を確認 |
| 場中（任意） | `streamlit run dashboard.py` で状況確認 |
| 判断時 | `python main.py paper-auto`（ルール通りの仮想売買） |
| 大引け後（15:30以降） | `python main.py close-day` → DAY1〜DAY5 として資産を記録 |
| DAY5 終了後 | `reports/` の日次レポートとバックテスト結果で振り返り |

`close-day` は毎日、開始資産・終了資産・前日比・累積利益率・10万円までの残額・必要残存倍率・残り営業日を記録します。
同じ日に再実行すると上書きされます。5日記録後は `python main.py reset -y` で再スタートできます。

## 8. バックテスト方法

```powershell
python main.py backtest            # 東証全銘柄・過去1年（時間がかかります）
python main.py backtest --quick    # 監視リストのみ（短時間）
python main.py backtest --research # 1株単位で検証
```

- ライブ分析と**同じスコア・BUY条件**を使用し、**4,100円の現金スタート**でシミュレーション
- 当日終値でシグナル → **翌営業日の寄付き**で仮想買付（未来のデータは使わない）
- 売却: 損切り / 利確 / トレーリング / 最大5日保有。同じ日に損切りと利確の両方に届いた場合は損切りを優先（保守的）
- 結果: 総取引回数・勝率・平均利益/損失・Profit Factor・期待値・最大ドローダウン・最大連敗・最終資産・リターン
- **Monte Carlo（1,000回）**: 中央値・上位10%・下位10%・最大資産・破産率（初期の50%以下）・10万円到達率
  - 取引サンプルが30件未満なら **「統計的信頼性不足」** と表示
  - 根拠のない「達成確率○%」は表示しません。Monte Carlo の数字も将来を保証しない参考値です
- 注意: 現在上場している銘柄だけで検証するため、上場廃止銘柄が含まれない（生存者バイアス）点に注意してください

## 10. モード

| モード | 内容 |
|---|---|
| `REALISTIC_MODE`（既定） | 100株単位・資金内のみ・現物のみ。**4,100円なら株価41円以下しか買えません** |
| `RESEARCH_MODE` | 1株単位の仮想売買。`--research` で切替。**松井証券でそのまま実行できる取引とは限りません**（画面に常時表示） |

## 12. よくあるエラー

| 症状 | 対処 |
|---|---|
| `python` が見つからない | Python再インストール時に「Add to PATH」にチェック |
| `価格データを1銘柄も取得できませんでした` | ネット接続を確認。社内ネットワークでは Yahoo Finance がブロックされる場合あり |
| 全銘柄の分析が遅い | `--quick` を使う、または `config.py` の `UNIVERSE = "watchlist"` |
| JPX一覧の取得に失敗 | 前回保存した一覧 → 監視リストの順で自動的に代替します |
| 整理銘柄などを除外したい | `config.py` の `EXCLUDE_CODES` にコードを追加 |
